# 三重枠ツール(Web版)

画像の上をマウスでドラッグするだけで「白・赤・白」の三重枠を描き込むツールです。
インストール不要、ブラウザだけで使えます(`index.html` を開くだけ)。

**画像はサーバーに送信されません。すべての処理はお使いのパソコンのブラウザの中だけで行われます。**
社外はもちろん、すろらぼの運営メンバー同士でも画像の中身が外部に送られることはありません。

---

## 使い方

### 画像を読み込む

- 画像ファイルをこのページにドラッグ&ドロップする
- 画像をコピーした状態で **Ctrl+V**(スクリーンショットなどをそのまま貼り付け)
- 上部ツールバーの「開く」ボタン、または **Ctrl+O**

### 枠を描く

- 画像の上をドラッグすると、離した位置までの範囲に三重枠(白→赤→白)が描かれます
- ドラッグした範囲の外周が、枠の一番外側になります
- 何個でも枠を描けます
- 画像の端をきれいに囲みたいときは、画像の外側までドラッグしてOKです。はみ出した分だけ画像が白背景で自動的に広がります(広がるのは最大で線の太さ×3pxまで)

### 拡大・縮小・移動

画面の一番下のバー(Windows「ペイント」と同じ並び)で表示倍率を変えられます。左端には現在の画像サイズが表示されます。

- 右下の「全体表示」アイコン: ウィンドウに収まる大きさに戻します(最大100%)
- 倍率のドロップダウン: 12.5% / 25% / 50% / 100% / 200% / 300% / 400% / 800% から選べます
- 虫眼鏡の「−」「＋」ボタンとスライダー(10%〜800%)でも変えられます
- **Ctrl+ホイール**: マウスカーソルの位置を中心に拡大縮小(1ノッチ約1.2倍)
- ショートカット: **Ctrl++** 拡大 / **Ctrl+−** 縮小 / **Ctrl+0** 全体表示(ブラウザ自体の拡大縮小の代わりに、画像の表示が変わります)
- 拡大して画像が表示領域より大きくなると、縦・横のスクロールバーが使えます。**ホイール**で縦スクロール、**Shift+ホイール**で横スクロールもできます
- **スペースキーを押しながらドラッグ**、または**右ボタン・中ボタンでドラッグ**でも表示位置を移動できます(スペース押下中はカーソルが手のひらになります)。左ドラッグは今までどおり枠を描きます
- 拡大して見ているときも、画像の外側の余白からのドラッグ(はみ出しドラッグ)は使えます
- 新しい画像を読み込んだときは「全体表示」から始まります。表示倍率を変えても、保存・コピーされる画像のサイズには影響しません

### 線の太さを変える

- ツールバーの「線の太さ」で 1〜30px の間で変更できます(+/−ボタンでも変更可)
- 白・赤・白の3本とも同じ太さになります
- 変更は **次に描く枠から** 反映されます。すでに描いた枠の太さは変わりません
- 設定した太さはブラウザに記憶され、次回開いたときも復元されます
- 「5pxに戻す」ボタンで初期値に戻せます

### その他の操作

| 操作 | 内容 |
|---|---|
| Ctrl+Z | 1つ前の状態に戻す(最大50回) |
| Ctrl+C | 加工後の画像をコピー(他のアプリに Ctrl+V で貼り付け可能) |
| Ctrl+S / PNGで保存 | PNG形式でダウンロード保存 |
| JPGで保存 | JPEG形式でダウンロード保存(透明部分は白になります) |

- 保存時のファイル名は、読み込んだファイルと同じ名前になります(拡張子だけ png/jpg に変わります)。貼り付けで読み込んだ場合は `frame_日付_時刻.png` のような名前になります。
- コピーに失敗するブラウザ・環境もあります。その場合は「PNGで保存」または「JPGで保存」ボタンを使ってください。
- 保存していない変更がある状態でページを閉じようとすると、確認メッセージが出ます。

## GitHub Pagesで公開する手順(非エンジニア向け)

社内共有用に、このツールをインターネット上のページとして公開する手順です。
一度公開してしまえば、あとはURLを共有するだけで誰でもブラウザから使えます。

> **注意:** GitHubの無料プランでは、公開に使うリポジトリを **Public(公開)** にする必要があります。
> ただし、このツールは画像をサーバーに送信せず、すべてブラウザ内で処理するため、
> 誰かがページを開いても画像の中身が外部に見られることはありません。
> (プログラムのコード自体は誰でも見られる状態になります)

1. **新規リポジトリを作成する**
   GitHubにログインし、右上の「+」→「New repository」から新しいリポジトリを作成します。
   - Repository name: 好きな名前(例: `triple-frame-web`)
   - Public を選択
   - 「Create repository」をクリック

2. **`index.html` をアップロードする**
   作成したリポジトリの画面で「Add file」→「Upload files」をクリックし、
   このフォルダの `index.html` をドラッグ&ドロップ(または選択)してアップロードします。
   最後に「Commit changes」をクリックして保存します。

3. **GitHub Pagesを有効にする**
   リポジトリ画面の上部メニューから「Settings」を開き、左側メニューの「Pages」をクリックします。

4. **公開設定をする**
   「Build and deployment」の「Branch」を
   - Branch: `main`
   - フォルダ: `/ (root)`

   に設定し、「Save」をクリックします。

5. **数分待つ**
   数分後、同じ「Pages」の画面に公開URL(`https://ユーザー名.github.io/リポジトリ名/`)が表示されます。
   そのURLを開くとツールが使えます。社内での共有には、このURLを配布してください。

更新したいときは、手順2と同様に `index.html` を再アップロード(上書き)すれば、数分後に反映されます。

## 既知の制限

- クリップボードへの画像コピー(Ctrl+C)は、ブラウザや環境によって対応していない場合があります(その場合は保存ボタンをご利用ください)。
- 非常に大きな画像はブラウザのメモリ制限により動作が重くなることがあります。
- Web版はブラウザの `<canvas>` を使って画像処理を行うため、極めて特殊なICCプロファイル・色空間を持つ画像では色の見え方がデスクトップ版とわずかに異なる場合があります。
